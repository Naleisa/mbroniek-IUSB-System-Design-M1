# Design System — CareMatch

## 1. Brand Principles
CareMatch should portray a trustworthy, calm, and dependable design.  It should be closer to a clinical design than a flashy startup.  The design should be warm and respectful toward caregivers, making the long and credential-heavy application feel doable rather than intimidating.  For agency staff, it should come across as confident and precise.  Every status, requirement, and blocked step should be plain and easy to check, so they never have to guess.

## 4. Logo Usage
- File(s): docs/design/carematchlogo.png 
- Do NOT: stretch, squash, or rotate the logo; change the colors or font; separate the checkmark from the wordmark; add shadows, outlines, or effects; place it on busy photos or low-contrast backgrounds; display it smaller than 120 px wide; crowd it (keep clear space around it at least the height of the letter "C").

## 5. Spacing & Grid
Default bootstrap spacing & grid patterns.

## 6. Core Components
List reusable UI patterns and their rules (e.g. radius, border, etc.).

| Component | Rules |
|-----------|-------|
| Button (primary) | Use #a93f55 with white text in Roboto medium.  Hover and pressed should be 10% darker.  One primary button per screen. |
| Button (secondary) | Transparent fill. 1px #a93f55 border and #a93f55 text. Hover fills with #a93f55 lighter tint. Supporting actions such as cancel. |
| Card | White background on #f3f7f0 page. 1px light gray border. |
| Form field | Label abovie field. Required fields are marked with an asterisk. |

## 7. Voice & Tone
Clear, warm, and professional voice, using short, plain language with no humor or jargon.

## 8. Accessibility Standards
- Minimum contrast ratio: 4.5:1 for body text (WCAG AA)
- Standard to meet: WCAG 2.1 AA
